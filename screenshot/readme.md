Deskripsi Project:

Project ini adalah sistem inventori barang sederhana yang dibuat untuk memenuhi tugas UTS. Sistem ini dibuat menggunakan PHP dan MySQL untuk mengelola data barang, stok barang, dan peminjaman barang. Tujuannya untuk memudahkan pencatatan barang agar lebih rapi dan tidak manual lagi.

Fitur-fitur yang ada:
1. Login admin untuk keamanan
2. Dashboard untuk melihat total barang dan stok
3. Tambah data barang baruEdit data barang
4. Hapus data barang
5. Menampilkan daftar barang dalam tabel

Struktur folder:
1. Folder admin berisi file untuk admin
2. Folder assets berisi file css dan gambar pendukung
3. Folder config berisi file koneksi database
4. Folder screenshot berisi foto-foto tampilan aplikasi seperti login, dashboard, tambah, dan edit

Teknologi yang dipakai:
PHP, MySQL, HTML, CSS, dan Bootstrap.

Cara menjalankan aplikasi:
1. Pindahkan folder project ini ke folder htdocs di XAMPP
2. Hidupkan Apache dan MySQL di XAMPP
3. Buat database baru di phpMyAdmin dengan nama db_inventoriImport file sql databaseBuka browser dan ketik localhost/UTS_Yohanna_25110089/
